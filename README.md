# Определение ориентации текста

Решение тестового задания Авито: для готового кропа текста определить вероятность поворота на **180°**. Результат — CSV с колонками `image_id` и `p_180` для 20 000 тестовых изображений. Основная метрика — **1 − Brier Score**.

## Подход

Используется **MobileNetV3-Small из torchvision** с предобученными весами ImageNet. Последний слой заменён на один выход; sigmoid преобразует его в `p_180`. Дообучаются все параметры модели.

Обучающие кропы получены из открытого датасета **HierText**. Слова выпрямляются по размеченным полигонам, затем случайно поворачиваются на 180° для формирования меток. Вход модели — RGB, 48 × 192, с сохранением пропорций и нормализацией ImageNet.

Аугментации обучения: наклон ±7° с вероятностью 50%, изменение яркости и контраста, размытие, уменьшение разрешения и JPEG-сжатие. При оценке случайные аугментации отключены.

Лучшая модель выбирается по Brier Score на `dev`. Там же выбирается TTA — объединение предсказаний исходного и перевёрнутого входа. Температура вероятностей подбирается на `calibration`; итоговый отчёт строится на `holdout`.

## Запуск

Нужны Python 3.11/3.12 и PyTorch с torchvision. Локальные проверки выполнялись с `torch==2.6.0` и `torchvision==0.21.0`; сборку PyTorch выбирают под CPU/CUDA. Остальные зависимости:

```bash
python -m pip install -r requirements.txt
```

В Jupyter или VS Code выбери Python окружения с установленными библиотеками. Ноутбуки запускаются сверху вниз из папки проекта или её подпапки.

1. **00** — проверь окружение. **01** — подготовь данные, если кропы ещё не созданы.
2. **02** — укажи `MANIFEST` и новую папку `RUN_DIR`, затем запусти обучение.
3. **03** — укажи **тот же `RUN_DIR` и `MANIFEST`**, проверь напечатанный путь к checkpoint и выполни оценку.
4. Для CSV укажи `TEST_DIR`, `SAMPLE_SUBMISSION`, включи `CREATE_SUBMISSION=True`. Если калибровка уже сохранена, используй `CALIBRATE=False`.

**Данные уже подготовлены: 02 → 03. Модель уже обучена: только 03.** Ноутбук 04 нужен при диагностике проблем, а не для каждого запуска.

По умолчанию папка весов — `runs/balanced_A_rot7_v1`. В 03 путь к checkpoint и имя CSV формируются из `RUN_DIR`. Переименование CSV не меняет используемую модель.

После завершённой эпохи сохраняется `last.pt` для продолжения обучения; при улучшении `dev_brier` обновляется `best.pt` для предсказаний. Продолжение: `RESUME=True` с прежними данными и конфигурацией. `STOP_AFTER_EPOCH` позволяет остановиться после заданной эпохи; для дальнейшего продолжения установи `None`.

## Воспроизводимость и ограничения

Вместе с весами сохраняются настройки, версии библиотек, хеши данных и выбор обучающих кропов. Разбиение выполняется по исходным фотографиям; точные дубликаты между частями удаляются. Проверки описаны в [VALIDATION.md](VALIDATION.md).

Тест Авито не размечается и не используется для обучения. Все предсказания выполняются локально, без внешних API. HierText отличается от целевых данных и содержит мало кириллицы, поэтому качество на нём не гарантирует аналогичный результат на Авито. Holdout уже использовался для оценки первой модели и не является новой независимой выборкой.
