# Проверки

Локально: Windows, Python 3.12, PyTorch 2.6.0 CPU. VM и реальные данные не используются.

- check_pipeline.py: подготовка кропов, правильная ориентация полигонов, отсутствие точных дубликатов
  между split, обучение, восстановление состояния, калибровка, CSV и повторный инференс в свежем ядре.
- check_rotation.py: диапазон наклонов, расширение холста, сохранение поведения старого CFG,
  применение только к train и неизменность меток dev.
- check_test_files.py: ID с расширением и без, порядок строк, неоднозначности, дубликаты и лишние файлы.

Все проверки создают временные изображения. Их метрики не являются оценкой качества на Авито.
